# Agent Instructions

This repository's agent/contributor conventions live in [`AGENTS.md`](../AGENTS.md) at the repository root — read it before making changes. It is the single source of truth (repository structure, pnpm/nvm/Corepack commands, the canonical component contract, token/Figma authority, package naming, and the `0.x`/`1.0.x` release policy) and is kept in one place so it doesn't drift between tool-specific copies.

Repository-local skills live in [`skills/`](skills/); see the [index](README.md). This file is tool-agnostic. Tool-specific entry points, such as `.github/copilot-instructions.md`, only link here.
