## When to use

Use an Icon Card for a single navigation destination. Keep its title clear and use an icon that supports the label. Use the external indicator for destinations outside the site. Icons are decorative and do not replace descriptive link text. See the [Card guide](../card/) for setup and accessibility guidance.

## When not to use

Do not use an Icon Card when there is no destination to navigate to, or as a topic heading or banner.

See the [Icon Card design in Figma](https://www.figma.com/design/jQ3EiYqe3uEvFbid5ewc41/Colorado-Design-System?node-id=2246-770). The Icon-only fixture is available at `@coloradodigitalservice/colorado-design-system/fixtures/card-icon.html`.
