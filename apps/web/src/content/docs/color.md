The Colorado palette combines state branding with colors used across digital services. Use the generated tokens in code rather than copying hex values; the values shown below help with inspection and contrast checks.

## Core color ramps

The base palette groups related colors into blue, plum, red, green, teal, yellow, and gray ramps. Each swatch is labeled with its shipped token and value. A color's presence in the palette does not mean it is suitable for every foreground and background combination.

## Semantic tokens

Semantic tokens name a color's purpose, such as an action background or default text. Prefer a role that matches its use instead of selecting a base color solely by appearance. Existing components provide their own supported colors and states.

## Contrast and accessibility

Check the actual foreground and background together: normal text generally needs at least 4.5:1 contrast, large text at least 3:1, and essential non-text indicators at least 3:1 against adjacent colors. Context and exceptions matter. Do not rely on color alone to communicate meaning; add text, icons, patterns, or other cues. Verify focus, hover, disabled, and forced-colors states in context.

The [Color design reference](https://www.figma.com/design/jQ3EiYqe3uEvFbid5ewc41/Colorado-Design-System?node-id=639-9934) provides additional palette guidance. Git's generated tokens are the source for the values and names shown here.
