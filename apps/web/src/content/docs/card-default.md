Use a Default Card to group related content or direct people to a single destination. Keep titles and descriptions concise. A flag card places media beside content on wider screens and stacks it on narrow screens. A media-only card needs an accessible link name. For multiple destinations, use separate links inside an unlinked container; never nest interactive elements inside a link. Use the external indicator for destinations outside the site. Choose meaningful image alternatives and heading levels for the surrounding page. See the [Card guide](../card/) for setup and accessibility guidance.
