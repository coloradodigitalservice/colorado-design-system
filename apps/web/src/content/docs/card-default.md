## When to use

Use a Default Card to group related content and direct people to a single destination. Keep titles and descriptions concise. A flag card places media beside content on wider screens and stacks it on narrow screens. A media-only card needs an accessible link name. For multiple destinations, use separate links inside an unlinked container; never nest interactive elements inside a link. Use the external indicator for destinations outside the site. Choose meaningful image alternatives and heading levels for the surrounding page. See the [Card guide](../card/) for setup and accessibility guidance.

## When not to use

Do not use a Default Card to organize information without an associated action, or when a topic needs multiple actions or links. Choose a pattern intended for multiple destinations. The shared Card guide also shows a non-linked container with separate links for cases that require it; destination type (internal or external) is separate from that link pattern.

See the [Default Card design in Figma](https://www.figma.com/design/jQ3EiYqe3uEvFbid5ewc41/Colorado-Design-System?node-id=1624-459). The Default-only fixture is available at `@coloradodigitalservice/colorado-design-system/fixtures/card-default.html`.
