# CoDS Governance

This directory contains the working governance controls for the Colorado Design System (CoDS). The documents define who makes decisions, how work is reviewed and approved, how changes are controlled, and how the repository and releases are operated.

All documents are currently **Draft for G0 approval** unless noted otherwise. Approval decisions, delegated authority, open conditions, and follow-up actions belong in the project decision log and the relevant backlog items.

## Start here

Use the documents in this order when establishing or reviewing delivery governance:

1. [Ownership and RACI](ownership-and-raci.md) defines accountable, responsible, consulted, and informed roles.
2. [Escalation and Decision Recording](escalation-and-decision-recording.md) explains how blockers, risks, disagreements, and material decisions are handled.
3. [Gate Approval Matrix](gate-approval-matrix.md) defines the evidence and approval roles for G0 through G5.
4. [Review Cadence and Response Expectations](review-cadence-and-response-expectations.md) sets review timing and response standards.
