# CoDS ownership by role

**Status:** Proposed for CODS-P0-002 review. This role matrix documents the intended review path; it does not grant GitHub permissions or replace an approved CODEOWNERS file.

| Area                                          | Responsible                     | Accountable                 | Consulted                                 |
| --------------------------------------------- | ------------------------------- | --------------------------- | ----------------------------------------- |
| Repository, scripts, and shared configuration | Aten technical lead             | State technology owner      | State security and release owners         |
| Design tokens                                 | Aten technical and design leads | State design owner          | State accessibility and technology owners |
| Core package and component contract           | Aten technical/component leads  | State technology owner      | State design and accessibility owners     |
| Astro reference site and content              | Aten documentation lead         | State content/product owner | State design and accessibility owners     |
| Storybook and quality checks                  | Aten component/quality leads    | State technology owner      | State accessibility owner                 |
| Governance and approval evidence              | Aten delivery lead              | State product owners        | Domain owners relevant to each gate       |
| CI, archives, and publication                 | Aten release lead               | State release owner         | State security and technology owners      |

The [upstream RACI](https://github.com/AtenDesignGroup/colorado-state-design-system/blob/main/docs/governance/ownership-and-raci.md) and [gate matrix](https://github.com/AtenDesignGroup/colorado-state-design-system/blob/main/docs/governance/gate-approval-matrix.md) remain the review references. CODS-P0-002 must confirm State-controlled GitHub teams, access, recovery, and actual CODEOWNERS identities before enforcement is added. No unverified team handles appear in this repository.
